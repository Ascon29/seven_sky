# Pet-проект приложения с телеграм-ботом

Реализован телеграм-бот подсчета зарплаты сотрудникам ресторана "7 Небо" для:
- официантов
- старших официантов
- барменов
- администраторов

Сам бот имеет команды:
- `/start` для запуска диалога
- `/cancel` для остановки диалога

На любые другие команды (сообщения с "/" вначале), бот отвечает, что не знает такую команду.

---
### Дополнительные функции бота. Реализованные для бота, добавленного в группу телеграм с правами администратора.

- ежедневное приветственное сообщение, наугад выбранное из списка `hello`. Список находится в дирректории `static/word_lists.py`
- реакция на video_notes (кружочки), наугад выбранная из списка `replicas`. Список находится в дирректории `static/word_lists.py`
- реакция на мат, находящийся в списке `abusive_words`. Список находится в дирректории `static/word_lists.py`
- приветствие / прощание с пользователями, вошедшими / покинувшими группу.
---
### Описание

- Код с ботом находится в директории `bot/management/commands/start_bot.py`
- Используется фреймворк Django только для дальнейшего развития.
---
### Запуск проекта

1) Клонировать репозиторий [Github](https://github.com/Ascon29/seven_sky/)\
2) Установить зависимости `pip install --no-cache-dir -r requirements.txt`
3) Заполнить `.env` файл. В параметр `TG_CHAT_ID` установить токен вашего телеграм бота.

Для запуска на локальной машине ввести команду `python manage.py start_bot`

Для развертывания Docker-контейнера:
- сборка контейнера `docker build -t my-django-app .`
- запуск контейнера `docker run -p 8000:8000 my-django-app`
